🏛️ Civic Participation Platform for Incidents

A full-stack, map-based civic engagement application that enables citizens to report, track, and locate local infrastructure issues or incidents in real time. The platform features an interactive interface with automated geolocation services, alongside a dedicated moderation workflow for administrative roles.

🌟 Key Features

Interactive Map & Geolocation

Geocoding & Reverse Geocoding support for pinpointing addresses directly on the map (built with Leaflet).

Incident Management

Citizens can create, view, and comment on reported incidents.
Interactive community voting ("This affects me") mechanism.

Role-Based Access Control (RBAC)

Multi-role authorization structure (Admin, Moderator, Contributor/User).
Moderator dashboard for handling reports, comment cleanup, and occurrence deletions with audit logging.

User Settings & Security

JWT-backed authentication.
User profile management, password updates, and toggleable password visibility settings.

🛠️ Tech Stack
Frontend: Angular, TypeScript, HTML, CSS, Leaflet

Backend: .NET Web API (C#), RESTful architecture, JWT Authentication

Tools & DevOps: Git, GitLab, feature branches
